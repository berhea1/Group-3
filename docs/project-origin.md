# Project origin and baseline

## Provenance

The machine-shop access-system prototype in this baseline was started by Omari Rich before the Senior Design course. The original work was maintained separately and was later adapted for Group 3's Senior Design project.

The purpose of the baseline pull request is to create a transparent integration point. It distinguishes pre-course work from the design, implementation, testing, documentation, and team contributions that happen during Senior Design.

## What enters the Senior Design repository in this baseline

- A FastAPI application and administrative interface
- A PostgreSQL bootstrap schema
- Docker and Docker Compose deployment files
- Example environment configuration with placeholder secrets
- Initial documentation for local and preview deployments

## Contribution boundary

The baseline should be treated as prior work contributed to the team, not as work newly completed during the course. Subsequent pull requests provide the auditable record of Senior Design changes, including requirements-driven features, kiosk integration, database migrations, tests, deployment changes, documentation, and contributions from other team members.

Git history should be preserved when this baseline is merged so its original author and date remain visible.
